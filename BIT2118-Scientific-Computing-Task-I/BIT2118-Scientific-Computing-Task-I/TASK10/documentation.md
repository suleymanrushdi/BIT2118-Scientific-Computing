
# Task 10: Bisection and Fixed-Point Iteration

## 1. Introduction
Root finding methods are numerical techniques used to find solutions of equations.

## 2. Objectives
- Understand the Bisection Method.
- Understand Fixed-Point Iteration.
- Implement both methods using Python.
- Compare their results.

## 3. Mathematical Function

The function used is:

f(x) = x³ - x - 2

The objective is to find the value of x where f(x) = 0.

## 4. Methods Used

### Bisection Method
The Bisection Method repeatedly divides an interval into two halves to locate a root.

### Fixed-Point Iteration
Fixed-Point Iteration repeatedly applies a rearranged equation until the result converges.

## 5. Inputs
- Initial interval: 1 to 2
- Initial guess: 1.5
- Tolerance: 0.0001

## 6. Expected Results
Both methods should approximate the root of the equation.

## 7. Real-World Applications
- Engineering calculations
- Scientific modelling
- Financial calculations
- Solving mathematical equations

## 8. Conclusion
Both methods provide numerical approaches for finding approximate roots of nonlinear equations.
