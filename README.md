This repository contains my individual coursework for BIT 2118 – Scientific Computing. It demonstrates the application of mathematical and numerical methods using Python programming.

The work covers different scientific computing concepts, practical programming exercises, and real-world applications.

The main objectives of this coursework are to:

6. How to Run the Programs
To run the programs:

Install Python on your computer.
Install the required libraries, such as NumPy and SciPy.
Clone or download this repository.
Open the repository in Visual Studio Code.
Open the relevant task folder.
Run the Python program using the VS Code terminal.
Example:

python Task_02_numpy_arrays.py
